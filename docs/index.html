Features

🎮 One-click playA big PLAY button that applies your quality profile and launches Roblox. No lock-in.
📊 Quality profilesLight, Medium and Full presets — each explains what it changes before applying.
⚡ FastFlags editorAllowlist-safe with human-readable descriptions. Advanced mode included.
💬 Discord Rich PresenceShow what you're playing on Discord, with the current game's name.
🧩 Mod managerInstall .zip mods into Sober's asset_overlay, protected against zip-slip.
⭐ Recent & favoritesReplay any game with one click from the home menu.
🌎 7 languagesEnglish, Português, Español, Français, Deutsch, Русский, 日本語 — switch instantly.

Install

1
Install Sober (the Roblox runtime for Linux):
flatpak install flathub org.vinegarhq.Sober
2
Download the AppImage from Releases and mark it executable:
chmod +x Soberix-*.AppImage
3
Run it (double-click works too) and hit PLAY.

FAQ

Is it a Bloxstrap clone?

It fills the same role on Linux, but it's an independent project: pure Python/GTK, managing Sober instead of the Windows client. No code shared with Bloxstrap.

Does Roblox ban you for using it?

Soberix only manages configuration — it doesn't modify the game, cheat, or touch Roblox's servers. It's in the same category as Bloxstrap and Sober themselves, which have operated openly for years.

Why does the Discord status need the Discord app?

Rich Presence works through a local socket only the Discord desktop app provides — the browser version can't receive it. This is true for Bloxstrap on Windows too.

My clicks are offset in the Discord app

That's a known Electron bug on fractional display scaling via XWayland. Launch Discord with --ozone-platform-hint=auto to run it native on Wayland.
